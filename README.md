# Cerberus: O Guardião do Submundo

Projeto Individual sobre mitologia grega, tendo como tema o Cerberus, o cão de três cabeças que guarda os portões do Hades.

## Estrutura
- `public/`: frontend (HTML, CSS, JavaScript)
- `src/`: API em Node.js
- `database/`: scripts SQL (modelo e comandos)
- `docs/`: documentação do projeto e Diário de Prompts
